agent-session-loop

一条流水线管理 Agent 会话的完整生命周期：深度复检（审查）→ 7 步收尾 → 复盘沉淀。

"AI 会话很少在做事的时候崩溃，多半是在收尾的时候：结论没验证就宣布完成，经验没沉淀就关窗走人，下一个 session 从零开始。"
Phase 1 · 审查

deep-review-loop

5 轮深度复检（R0-R3）+ 4 层过拟合防护。审查 → 修复 → 重新审查，杜绝假收敛。

 Phase 2 · 收尾

mem-wrap-up

7 步收尾流水线 + 6 面状态矩阵。验证铁律：不信任「已落地」声明，Grep 为准。

 Phase 3 · 沉淀

self-evolution

3 问自检 / 11 维度复盘，经验 → pattern → heuristic → policy，让经验可复利。
